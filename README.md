# School Management System

## Overview

The School Management System is a web-based application developed to help schools manage their daily academic and administrative activities efficiently. The system provides a centralized platform where administrators, headmasters, teachers, students, and parents can access and manage important school information.

This project was developed using PHP, HTML, CSS, JavaScript, and MySQL.

## Features

### Admin

* Register and manage headmasters
* Manage schools, teachers, and students
* View system statistics and reports
* Edit and delete user accounts

### Headmaster

* Manage teachers and students
* View school performance reports
* Monitor attendance and academic records

### Teacher

* Manage student records
* Record attendance
* Enter and update examination results
* View class information

### Parent

* View personal profile
* Check attendance records
* Access examination results
* View academic progress

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/school-management-system.git
   ```

2. Move the project folder to your web server directory:

   * XAMPP: `htdocs`
   * WAMP: `www`

3. Create a MySQL database.

4. Import the provided SQL file into the database.

5. Update database credentials in:

   ```php
   config/database.php
   ```

6. Start Apache and MySQL.

7. Open your browser and visit:

   ```
   http://localhost/school-management-system
   ```
